# HR Analysis Project 📊
Author: Foo Chit Long Darren
Date: January 2025

## 📌 Overview
This project is an HR Analytics study conducted on a synthetic dataset from Kaggle, focused on understanding key human resource trends, including employee retention, recruitment effectiveness, manager performance, pay rate factors, and workforce demographics. The analysis was performed using data visualization and statistical techniques to provide actionable insights for business decision-making.

## 📂 Project Contents
The project includes:

- Exploratory Data Analysis (EDA): Company demographics, workforce distribution, and retention rates.
- Recruitment Source Analysis: Identifying the best hiring channels based on cost-effectiveness and performance.
- Manager Performance Evaluation: Ranking managers based on retention, revenue contribution, and team success.
- Pay Rate Factors: Investigating gender pay disparities and departmental salary distribution.
- Employee Retention: Understanding characteristics of employees likely to leave and strategies to improve retention.
- Interactive Dashboard: A Tableau dashboard for real-time data exploration.
